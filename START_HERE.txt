LIFE TRACKER — ЗАПУСК НА WINDOWS

1. Полностью распакуйте архив в обычную папку. Не запускайте файл из открытого ZIP.
2. Дважды нажмите START.vbs. Приложение откроется в браузере по умолчанию. Команды и установка Node.js для этого не нужны.
3. Чтобы остановить фоновый локальный сервер, дважды нажмите STOP.vbs. При повторном открытии он запустится снова. Сервер также завершается при выключении компьютера.

Важно: данные хранятся в браузере и привязаны к адресу http://127.0.0.1:51827/. Это отдельное хранилище от сайта на GitHub Pages и от других браузеров. Для переноса сначала экспортируйте JSON из старой версии, затем при необходимости импортируйте его в новой через «Ещё → Данные». Импорт заменяет текущие данные — сначала сделайте их копию.

Не удаляйте и не переименовывайте папку launcher и папку dist. Если порт 51827 занят, появится сообщение: закройте другую копию или приложение, которое его использует. Если Windows запрещает выполнение VBS/PowerShell, обратитесь к администратору устройства.

Здесь приложена локальная сборка. Публикация на GitHub Pages и перенос ваших данных не выполнялись. Данные на телефоне с локальной версией ПК автоматически не синхронизируются.
