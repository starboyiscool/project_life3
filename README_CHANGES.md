# Обновление оформления

В проекте обновлено оформление и добавлены: учебные сроки на «Сегодня», восстановление снапшота, отмена удаления задачи, быстрый повтор последних порций продукта и калькулятор блинов. Схема IndexedDB не менялась; настройки блинов сохраняются локально в существующей таблице настроек и включаются в экспорт.

Калькулятор находится во время тренировки в упражнении со штангой. В нём укажи вес грифа и доступное количество **пар** блинов, затем сохрани настройки. Если точный вес недоступен, показывается ближайший; вес подхода при этом не меняется. Исходный план и статус каждого пункта — в `PLAN_DORABOTOK.md`.

Фоновое уведомление таймера не добавлено: браузер может ограничивать фоновые таймеры и останавливать service worker. Надёжность при блокировке экрана не проверена на Android; текущий звук и вибрация рассчитаны на открытую вкладку.

## Запуск на Windows без консоли

Полностью распакуйте архив и дважды нажмите `START.vbs`. Откроется браузер; Node.js и установка зависимостей не нужны. Чтобы остановить фоновый локальный сервер, дважды нажмите `STOP.vbs`. Подробности — в `START_HERE.txt`.

Локальный адрес `http://127.0.0.1:51827/` имеет отдельные данные от GitHub Pages и других браузеров. Чтобы перенести данные, сначала экспортируйте JSON из старой версии. Импорт заменяет текущие данные, поэтому предварительно сохраните их копию. Телефон автоматически с ПК не синхронизируется. После изменений исходного кода сначала пересоберите `dist` для корня сайта.

## Запуск для разработки

Установите Node.js LTS, распакуйте архив, откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Для проверки производственной сборки: `npm run build`, затем `npm run preview`. Для GitHub Pages продолжайте использовать существующий `npm run deploy` или сборку с корректным `BASE_PATH`; приложенный `dist` собран для корня сайта, а не `/life/`.

В архив не включены `node_modules` и `.git`: зависимости устанавливаются командой выше, а история Git остаётся в вашем исходном репозитории. Если хотите продолжить работу в нём, перенесите изменённые файлы из архива в существующую папку проекта, не заменяя `.git`.

Перед обновлением установленного приложения рекомендуется экспортировать JSON-бэкап через «Ещё → Данные». Данные в браузере привязаны к адресу сайта: локальный запуск и опубликованная версия не делят одну базу автоматически. Публикация и перенос данных не выполнялись.

Проверки: `npm run check`, `npm test` (94 теста), `npm run build`.
