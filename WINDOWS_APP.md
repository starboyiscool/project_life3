# Windows-приложение Life Tracker

Веб-версия обёрнута в настольное приложение на **Electron** (отдельное окно, полный офлайн, данные в IndexedDB). Сборка лежит в `release/`:

| Файл | Что это |
|---|---|
| `release/LifeTracker-Setup-0.0.1.exe` | Установщик (one-click, ставит в `%LOCALAPPDATA%\Programs`, без прав администратора) |
| `release/LifeTracker-Portable-0.0.1.exe` | Портативная версия одним файлом (самораспаковывается во временную папку при запуске) |
| `release/win-unpacked/` | Несобранное приложение — `Life Tracker.exe` внутри можно запускать напрямую |

## Как запустить

- **Установка:** двойной клик по `LifeTracker-Setup-0.0.1.exe`. Установится в меню «Пуск» и на рабочий стол.
- **Без установки:** двойной клик по `LifeTracker-Portable-0.0.1.exe` (первый запуск чуть дольше — распаковывается).

Приложение не подписано цифровой подписью, поэтому Windows SmartScreen при первом запуске может показать предупреждение «Windows защитил ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

## Данные

- Данные хранятся локально в IndexedDB в профиле пользователя (`%APPDATA%\Life Tracker`). Это **отдельное** хранилище от браузерной версии (GitHub Pages / локального `START.vbs`).
- Чтобы перенести данные из браузерной версии: в старой версии «Ещё → Данные → Экспорт», в приложении «Ещё → Данные → Импорт».
- Резервные копии по-прежнему доступны через «Ещё → Данные». Не забывайте раз в неделю делать экспорт JSON.

## Пересборка (для разработки)

```sh
npm ci
npm run icon:ico        # сгенерировать build/icon.ico (нужно один раз)
npm run build:desktop   # vite build --base=./ + electron-builder (установщик + portable)
```

Важно: NSIS-установщик падает, если путь к проекту содержит кириллицу (например, `C:\Users\Алекс\...`). Собирайте из ASCII-пути (например, `C:\lt\`), либо скопируйте проект в папку без не-ASCII символов перед `electron-builder`. Артефакты появятся в `release/`.

Исходники обёртки: `electron/main.cjs` (main-процесс) и конфиг `build` в `package.json`.
